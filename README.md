# Amalagme-Balatro-mod
Jokerforge file for the mod i made

All art for this mod was done by me, and the code for the jokers came from jokerforge.
To download the mod, drag and drop the file into your mods folder. Steammodded is required.
NO AI WAS USED IN THE CREATION OF THIS MOD! If you find any issues, let me know, but no guarantee that I'll get around to fixing it.
